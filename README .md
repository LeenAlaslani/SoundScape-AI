# SoundScape AI 🌧️🔥

**Deep Learning for comforting, customizable background sounds.**

Users will choose a calming scene (rain on a window, fireplace, forest, beach) and adjust the **relative volume** of two or three generated sound layers. Example: **rain 20 + fire 70 + birds 10**. Each category is generated by one of **two independently trained models**; a future unified mixer combines their WAV outputs. Scene images and Agentic AI are **planned**, not implemented yet.

Each notebook independently installs dependencies, downloads ESC-50, audits quiet audio, prepares mel spectrograms, trains a **conditional convolutional VAE**, plots learning curves, evaluates on an untouched test fold, and exports a `.pt` model checkpoint and example `.wav` files. No `src/`, imports from sibling files, or local dataset preparation are required.

## Scientific setup

- **Dataset:** [ESC-50](https://github.com/karolpiczak/ESC-50) — 2,000 labeled 5-second recordings, 50 categories, **40 recordings per category**. Each notebook selects 5 classes (200 original samples). This is a **prototype**, not enough to assume high-fidelity generation.
- **Train / validation / test:** official ESC-50 folds **1–3 / 4 / 5**. No test leakage for hyperparameter selection.
- **Audio contract:** 16 kHz mono, 5-second WAV, 64 × 320 mel features, fixed dB reference; independent `.pt` checkpoints with class names and parameters.
- **Data audit:** some files contain long quiet spans. Quiet frames and zero samples are recorded, **not silently discarded**. Original duration is checked before padding.
- **Model:** conditional convolutional variational autoencoder; mel L1 reconstruction + KL divergence. Mel-to-wave inversion uses **Griffin–Lim**, which can sound unnatural.
- **Evaluation:** train/validation losses, held-out mel L1 error, **human listening** for perceived naturalness/comfort, and baseline comparison. Low loss alone does **not** mean pleasant audio.

## Planned integration

1. Run both notebooks in Colab, independently train and download checkpoints.
2. A platform loads the two checkpoints separately, generates audio layers and adjusts **relative gains** (rain 20 / fire 70 / birds 10). These numbers are **not exact perceptual percentages**.
3. Add matching scene images and smooth loops after sound quality is acceptable.
4. Optionally implement an Agentic AI scene planner/evaluator after the core Deep Learning work is validated.

**Not implemented yet:** unified sound mixer/website, real-time generation, scene image generation, Agentic AI. **Training has not been run end-to-end on a Colab GPU yet**; please run and inspect results.
